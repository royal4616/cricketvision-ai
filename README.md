# CricketVision AI

AI-assisted cricket video analysis for 60 FPS delivery footage.

## MVP
- Upload/local browser video analysis
- Validate FPS when metadata is available
- Frame-by-frame delivery timing
- Calibrated bowling-speed calculation
- Delivery tagging
- Batsman shot tagging
- Delivery-by-delivery commentary
- Session summary and analytics

## Accuracy note
Video-derived speed is an estimate. The MVP exposes the selected frames, distance, FPS, and timing so the calculation is auditable.
